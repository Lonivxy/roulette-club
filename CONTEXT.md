# Domain vocabulary

- Account: Sites-authenticated visitor identity, owns one player and a site role.
- Player: existing game persona, wallet, debts, cards and history; never an authentication credential.
- Formal wallet: real in-game accounting in casino_state; fictional chips with no monetary value.
- Sandbox: isolated administrator game simulation; never grants formal assets or progression.
- Round: one fully settled game outcome, not a click/blackjack hit/stake placement.
- XP: bounded progression awarded from verified events; not currency.
- Club: one private friends group per player; club owner is not a platform administrator.
- Claim: a unique, server-validated reward transaction for one player and one reward instance.
- Opening record: exact state at V2 activation; does not invent prior transaction history.
